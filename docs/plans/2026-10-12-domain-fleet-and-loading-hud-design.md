# 技能领域大舰队与全景战术折跃 Loading 设计规范

**日期**: 2026-10-12  
**状态**: Approved & In Progress  
**关联方案**: 知识宇宙 3D 星图 · 技能空间站舰队系统与转场交互

---

## 1. 需求与核心目标

1. **更加明显的 Loading 页面**：
   - 解决此前仅在顶栏小区域输出遥测文本、缺乏科幻冲击力的问题。
   - 实现居中沉浸式战术折跃 HUD 遮罩（全息双环反向自转战术陀螺仪、量子核心、扫描线背景）。
   - 动态输出跃迁状态 `[HYPERSPACE TRANSIT]` 与实时遥测日志流（`[NAV-VECTOR]`、`[SYNAPSE-MAP]`、`[BATTLEGROUP]`）。
   - 搭载量子流光能量进度条，支持全屏点击激发 EMP 脉冲爆炸与星尘火花，悬停加速自转，数据就绪后平滑折跃消隐。

2. **技能领域大舰队集群（无上限动态分类 + 大舰队模型 + 附带小舰队）**：
   - **动态领域分类器**：针对本地 492+ 技能，基于功能语义、元数据与目录路径进行无上限动态领域聚类（如 UI视觉设计、动效多媒体、创意写作与提示词、Agent智能编排、代码工程与架构、质量测试、API协议防御、数据科学检索、DevOps工具链、探索思考认知、通用特遣等）。只要出现新领域，自动生成对应舰队。
   - **大舰队模型（Capital Flagship）**：每个领域由一艘 2.2x 标度的战列母舰/重型指挥旗舰统领，具备独立重型舰体骨架、指挥塔天线、多环旋转偏转能量屏障与专属领域徽标。各大旗舰在 360° 立体空间中围绕母港形成扇面防御与巡航战位。
   - **附带小舰队（Escort Squadron）**：该领域下的各个具体 Skill 作为护航舰艇（尖锥突击机、截击机、巡洋护卫），环绕在该领域的旗舰周围，随旗舰同步机动巡航。
   - **交互下钻**：点击领域旗舰平滑聚焦该大舰队；点击具体护航小战舰展开 Skill 详情。

### 2.2 3D 舰队拓扑布局 (`buildUniverseLayout`)
- **星系母港（Starbase Hub）**：`🛸 技能空间站`（母港中枢，深空独立漂流）；
- **一级节点（大舰队旗舰）**：各大领域旗舰（例如 `UI-Carrier`、`Muse-Dreadnought`、`Swarm-Flagship` 等），各旗舰距母港中枢形成立体战术巡航轨道；
- **二级节点（护航战术小机群）**：该领域下的各技能舰船，以对应领域旗舰为局部坐标原点进行战术机动布局。

### 2.3 沉浸式 Loading HUD (`#universe-warp-loading`)
- DOM 结构：全屏暗场半透明遮罩 + 居中战术玻璃面板；
- 视觉组件：双环陀螺仪刻度盘 + 核心脉冲核 + 状态指示 + 遥测数据流 + 量子能量进度条；
- 交互机制：`pointerdown` 激发电磁 EMP 粒子波，悬停加速罗盘自转。
