    目录

    这些开关保存在本机 preferences.json，只影响本机行为，不会改变任何已授权 Agent 的权限。

    检索索引由后台 worker 自动维护：未就绪时全量重建，就绪后增量跟随入库事件（也会比对 canonical 修订以捕获没有 outbox 的写入）。不需要开关，需要强制全量重建时用「系统与索引」里的按钮。

    自动入库

    开启后，客户端可在会话结束时把摘要写入本库（写入方显示为 mcp-agent:<principal>，不冒充用户）。真正触发还需要在客户端配置 Hook；本开关只表示本库是否接受。
